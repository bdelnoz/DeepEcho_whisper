# DeepEcho_whisper

DeepEcho_whisper is a shell-based toolkit for installing Whisper environments and transcribing video files with `whisper.cpp`.

## Repository Scope

This repository currently includes:

- Installation automation via `install_whisper.sh`.
- Multiple transcription script versions (`transcribe_mp4.*.sh`) kept in the root directory.
- A bundled `whisper.cpp` source tree.
- Execution logs generated by script runs.

## Main Scripts and Current Usage

### 1) `install_whisper.sh`

Purpose:

- Creates a Python virtual environment (`whisper_env`).
- Installs `openai-whisper` through `pip`.
- Clones or updates `whisper.cpp`.
- Builds `whisper.cpp` and validates `whisper-cli`.
- Downloads at least `ggml-base.bin` model.

Key options:

- `--help`
- `--clean`
- `--reinstall`
- `--test <audio_file>`

### 2) `transcribe_mp4.2.3.sh`

Purpose:

- Handles single-file (`--file`) and batch (`--folder`) video transcription.
- Extracts WAV 16kHz mono audio before transcription.
- Supports optional audio compatibility analysis (`--analyze`).
- Produces text outputs in selected formats (`--output-format`, default `txt,srt,vtt`).
- Provides deletion mode for generated artifacts (`--delete`).

Key options:

- `--file <path>`
- `--folder <path>`
- `--exec`
- `--analyze`
- `--model <name>`
- `--lang <code>`
- `--threads <n>`
- `--output-format <formats>`
- `--keep-audio`
- `--delete`
- `--help`

> Note: this script file name is `transcribe_mp4.2.3.sh` but the internal header/version references `v2.2`.

## Quick Start

### Prerequisites

- Linux environment with Bash.
- `python3`, `pip3`, `git`, `cmake`, `make` for installation workflow.
- `ffmpeg` and `ffprobe` for transcription and analysis.

### Install stack

```bash
chmod +x install_whisper.sh
./install_whisper.sh
```

### Analyze a single video

```bash
chmod +x transcribe_mp4.2.3.sh
./transcribe_mp4.2.3.sh --file "/path/video.mp4" --analyze
```

### Run batch transcription

```bash
./transcribe_mp4.2.3.sh --folder "/path/videos" --exec --model large-v3 --lang en
```

## Output Behavior

- Logs are written to script-defined log files in repository root.
- Transcription files are generated next to source videos.
- The bundled `whisper.cpp` directory is used as the default runtime backend.

## Legacy Script Versions

The repository keeps older script revisions (`transcribe_mp4.v1.7.sh`, `transcribe_mp4.1.9.sh`, `transcribe_mp4.2.1.sh`, `transcribe_mp4.bof.sh`) for historical comparison and rollback convenience.
